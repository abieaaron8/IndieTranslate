# IndieTranslate

Offline real-time Indic language translation platform.

## Features

- Offline IndicTrans2 translation
- React + TypeScript frontend
- FastAPI backend
- WebSocket streaming
- Speech recognition
- Local AI inference
- Supports multiple Indian languages

## Tech Stack

- React
- TypeScript
- FastAPI
- PyTorch
- HuggingFace Transformers
- IndicTrans2

## Setup

Backend

cd backend
python -m venv .venv
pip install -r requirements.txt
